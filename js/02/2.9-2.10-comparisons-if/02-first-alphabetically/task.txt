ЗАДАЧА 2.9-2 — FIRST ALPHABETICALLY (сравнение строк)


О ЧЁМ ЗАДАЧА

Строки в JS можно сравнивать через < и >, как числа. Но сравниваются они
не "по алфавиту" в человеческом смысле, а по кодам символов, посимвольно
слева направо. Из этого вылезает пара сюрпризов.


ЧТО ИМЕННО ПИСАТЬ

Файл solution.js:

    export function getFirstAlphabetically(left, right) { ... }

Обе строки. Вернуть ту, которая "меньше" при сравнении через <.
Если строки равны — вернуть любую из них (они одинаковые).

Решение — одна строка через тернарный оператор (тема 2.10).


ПРИМЕР

    getFirstAlphabetically('аня', 'борис')   // 'аня'
    getFirstAlphabetically('борис', 'аня')   // 'аня'
    getFirstAlphabetically('аня', 'аня')     // 'аня'


СЮРПРИЗЫ, КОТОРЫЕ ПРОВЕРЯЮТ ТЕСТЫ (в этом вся соль)

1. Числа в виде строк сравниваются НЕ как числа:

       '10' < '2'    // ? проверь в консоли

   Посимвольно: сравнивается '1' против '2', и на этом всё решается —
   до второго символа дело даже не доходит.

2. Регистр важен. Заглавные буквы идут по кодам РАНЬШЕ строчных:

       'Б' < 'а'     // ? проверь в консоли

   Поэтому 'Борис' окажется "раньше" чем 'аня', хотя по-человечески
   алфавит говорит обратное. Это не баг твоего кода, это так и работает —
   тест на этот случай специально есть, и ожидает именно такое поведение.

   (Привести обе строки к одному регистру было бы правильнее, но методы
   строк — это глава 5, мы до неё не дошли. Пока просто увидь эффект.)


ОГРАНИЧЕНИЕ

Только сравнение и тернарник. Без логических операторов (&& || !) — они
идут в теме 2.11. Без методов строк, массивов и объектов.
