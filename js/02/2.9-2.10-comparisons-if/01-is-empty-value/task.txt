ЗАДАЧА 2.9-1 — IS EMPTY VALUE (null, undefined и нестрогое равенство)


О ЧЁМ ЗАДАЧА

Очень частая проверка в реальном коде: "значение вообще есть или его нет?".
Отсутствие значения в JS бывает двух видов — null и undefined. Нужно
поймать оба, но не спутать их с нулём, пустой строкой и прочим.


ЧТО ИМЕННО ПИСАТЬ

Файл solution.js:

    export function isEmptyValue(value) { ... }

Вернуть true, если value — это null или undefined.
Вернуть false во всех остальных случаях.


ПРИМЕР

    isEmptyValue(null)        // true
    isEmptyValue(undefined)   // true

    isEmptyValue(0)           // false
    isEmptyValue('')          // false
    isEmptyValue(false)       // false
    isEmptyValue(NaN)         // false
    isEmptyValue('привет')    // false


ВАЖНО, НЕ ПУТАЙ С ПРОШЛОЙ ЗАДАЧЕЙ

В теме 2.7 была isFilled — там пустая строка и ноль считались "ложными".
Здесь НЕ ТАК: ноль и пустая строка — это вполне себе значения, они есть.
Нет — только null и undefined.


ПОДУМАЙ НАД ЭТИМ (суть темы 2.9)

Проверь в консоли и сравни результаты:

    null === undefined     // ?
    null == undefined      // ?
    null == 0              // ?
    null >= 0              // ?

Первые два — ровно про разницу между строгим и нестрогим равенством.
У Кантора в главе "Сравнения" отдельно разбирается, почему null и undefined
при нестрогом сравнении равны друг другу, но при этом null не равен нулю.

Решить задачу можно двумя способами: в лоб (двумя проверками) или одной
короткой строчкой, если использовать то самое свойство нестрогого
равенства. Оба варианта засчитываются — но попробуй найти короткий.


ОГРАНИЧЕНИЕ

Логические операторы (&& || !) — это тема 2.11, её ты ещё не читал.
Обойдись без них: отдельными if или одним сравнением.

Массивов, объектов и их методов тоже нет.
