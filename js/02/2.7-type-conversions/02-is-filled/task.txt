ЗАДАЧА 2.7-2 — IS FILLED (логическое преобразование)


О ЧЁМ ЗАДАЧА

Проверяем, "заполнено ли поле". Звучит просто, но в JS логическое
преобразование (Boolean) устроено не так, как многие ожидают, и тут пара
неожиданных случаев.


ЧТО ИМЕННО ПИСАТЬ

Файл solution.js:

    export function isFilled(value) { ... }

value — любое примитивное значение: строка, число, null, undefined,
логическое значение.

Вернуть true, если значение по правилам JS считается "истинным" (truthy),
и false, если "ложным" (falsy).

Проще говоря: вернуть результат логического преобразования этого значения.


ПРИМЕР

    isFilled('привет')    // true
    isFilled(42)          // true
    isFilled(true)        // true

    isFilled('')          // false   пустая строка — ложная
    isFilled(0)           // false
    isFilled(null)        // false
    isFilled(undefined)   // false
    isFilled(false)       // false
    isFilled(NaN)         // false


ЛОВУШКИ (проверь каждую сам в консоли, прежде чем писать код)

    isFilled('0')         // ???
    isFilled(' ')         // ???
    isFilled('false')     // ???
    isFilled(-1)          // ???

Вот эти четыре — главное в задаче. Подумай, что должно получиться по
правилам JS, проверь в консоли, и только потом пиши решение. Если
результат тебя удивит — это и есть тот момент, ради которого тема
существует.


ОГРАНИЧЕНИЕ

Только переменные, примитивы, преобразование типов. Никаких массивов,
объектов и их методов.

Решение короткое — если пишешь длинную лесенку из if, значит идёшь не
туда: в JS есть прямой способ получить логическое значение из чего угодно.
