ЗАДАЧА 2.7-1 — PARSE AGE (строка -> число)


О ЧЁМ ЗАДАЧА

Классическая ситуация: пользователь что-то ввёл (prompt всегда возвращает
СТРОКУ, даже если человек набрал цифры). Надо превратить эту строку в число,
но аккуратно — потому что ввести могли что угодно.


ЧТО ИМЕННО ПИСАТЬ

Файл solution.js:

    export function parseAge(input) { ... }

input — строка (то, что "ввёл пользователь").

Вернуть число, если строка реально содержит число.
Вернуть null, если введено не число.


ПРИМЕР

    parseAge('25')        // 25      (именно число, не строка!)
    parseAge('  25  ')    // 25      пробелы по краям не мешают
    parseAge('3.5')       // 3.5
    parseAge('0')         // 0
    parseAge('-7')        // -7

    parseAge('abc')       // null
    parseAge('25лет')     // null
    parseAge('')          // null    <- ВНИМАНИЕ, см. ниже


ГЛАВНАЯ ЛОВУШКА (ради неё задача и существует)

Проверь сам в консоли (node -e "console.log(Number(''))"), что вернёт
Number('') — пустая строка. Результат многих удивляет, и он точно не тот,
который нам нужен для возраста. Значит, пустую строку придётся отсечь
ОТДЕЛЬНО, до конвертации или после — как посчитаешь логичнее.


ИНСТРУМЕНТ, КОТОРЫЙ ПОНАДОБИТСЯ

Результат неудачной конвертации (Number('abc')) — это NaN, специальное
значение "не число". Поймать его обычным сравнением нельзя: NaN === NaN
даёт false (проверь сам, это не опечатка).

Проверяют так:

    Number.isNaN(значение)   // true, если это именно NaN

Формально Number.isNaN у Кантора разбирается позже, в главе про числа,
но без него эту тему честно не пройти — поэтому просто бери как данность.


ОГРАНИЧЕНИЕ

Только переменные, числа, строки, if. Никаких массивов, объектов, их
методов и регулярок — мы это ещё не проходили.
