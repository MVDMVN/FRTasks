ЗАДАЧА 6 — DISCOUNTED PRICE (деструктуризация с дефолтами)


О ЧЁМ ЗАДАЧА

Та же деструктуризация объекта, что ты пишешь в пропсах React-компонентов
(function Button({ label, onClick, disabled = false })), только на входе
обычный объект товара, а не пропсы.


ЧТО ИМЕННО ПИСАТЬ

Файл solution.js:

    export function getFinalPrice({ price, discount = 0 }) { ... }

Аргумент — не два отдельных параметра, а ОДИН объект, из которого через
деструктуризацию сразу достаём price и discount. Если discount не передан —
считаем его равным 0 (это и есть дефолтное значение в деструктуризации).

discount — это доля от 0 до 1 (0.2 значит скидка 20%).

Вернуть итоговую цену после скидки: price - price * discount.


ПРИМЕР

    getFinalPrice({ price: 1000, discount: 0.2 })
    // 800

    getFinalPrice({ price: 500 })
    // 500 — discount не передан, взят дефолт 0

    getFinalPrice({ price: 1000, discount: 0 })
    // 1000 — discount передан явно как 0, дефолт тут ни при чём,
    // просто скидки нет


ОГРАНИЧЕНИЕ

Деструктуризация прямо в параметрах функции, без отдельной строки
const { price, discount } = ... внутри тела.
