ЗАДАЧА 8 — OMIT PASSWORD (rest в деструктуризации объекта)


О ЧЁМ ЗАДАЧА

Реальная ситуация: с бэкенда пришёл юзер целиком, вместе с password (хэш
или как есть — неважно). Отдавать это на фронт/в UI нельзя. Нужно вернуть
копию объекта без поля password, остальные поля — как есть.


ЧТО ИМЕННО ПИСАТЬ

Файл solution.js:

    export function omitPassword(user) { ... }

user — объект вида { id, name, email, password, ... } (могут быть любые
другие поля, не только эти).

Вернуть новый объект — те же поля, что и в user, кроме password.


ПРИМЕР

    const user = {
      id: '1',
      name: 'Аня',
      email: 'anya@mail.com',
      password: 'qwerty123',
    }

    omitPassword(user)
    // { id: '1', name: 'Аня', email: 'anya@mail.com' }
    // password нет вообще, даже как undefined

    user
    // не изменился, password на месте — исходный объект не трогаем


ОГРАНИЧЕНИЕ (в этом весь смысл)

Решить через деструктуризацию с rest-оператором (...), одной строкой:

    const { password, ...rest } = user

А не через delete, не через ручное перечисление полей (id, name, email —
это подглядывание в структуру объекта, а функция должна работать с ЛЮБЫМ
набором полей, лишь бы password среди них был).


ПРОВЕРКА

    node --test 01-js/08-omit-password/solution.test.js

Зелёные тесты = задача сдана.
