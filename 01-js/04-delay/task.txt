ЗАДАЧА 4 — DELAY


О ЧЁМ ЗАДАЧА

Максимально простая задача, только одна идея: как обернуть setTimeout в
промис. Больше ничего — ни ошибок, ни циклов, ни ретраев.


ЧТО ИМЕННО ПИСАТЬ

Файл solution.js:

    export function delay(value, ms) { ... }

delay должна вернуть Promise, который зарезолвится значением value через
ms миллисекунд. И всё.


ПРИМЕР

    const result = await delay('привет', 100)
    // result === 'привет', но получили мы его только через 100мс,
    // не раньше

    console.log('старт')
    const promise = delay('готово', 200)
    console.log('это выведется сразу, а не через 200мс')
    console.log(await promise)
    // 'готово', примерно через 200мс после старта


ЧТО ВАЖНО ПОНЯТЬ (для себя, не для теста)

delay(value, ms) сама по себе не async function — она просто СОЗДАЁТ и
СРАЗУ ВОЗВРАЩАЕТ промис (обычным return, без await внутри delay). А ждёт
уже тот, кто ПОТОМ напишет await delay(...) — в тесте, например.
