ЗАДАЧА 3 — RETRY


О ЧЁМ ЗАДАЧА

Есть асинхронная функция, которая иногда падает (например запрос к серверу,
который иногда не отвечает). Нужна обёртка retry(fn, retries, delay),
которая сама повторяет попытки при ошибке.


ЧТО ИМЕННО ПИСАТЬ

Файл solution.js:

    export async function retry(fn, retries, delay) { ... }

fn        — асинхронная функция без аргументов, возвращает Promise
retries   — сколько всего попыток сделать (не "повторов", а всего вызовов fn)
delay     — сколько миллисекунд ждать между попытками

Поведение:

1. Вызвать fn(). Если получилось (промис зарезолвился) — вернуть результат,
   больше ничего не делать.

2. Если fn() упала (промис отклонился) — подождать delay мс и попробовать
   ещё раз.

3. Так до тех пор, пока не кончатся попытки (всего retries штук).
   Если и последняя попытка упала — retry должна отклониться той же
   ошибкой, что была в последней попытке.


ПРИМЕР

    let attempt = 0

    async function unstable() {
      attempt++
      if (attempt < 3) throw new Error('fail')
      return 'ok'
    }

    await retry(unstable, 5, 10)
    // -> 'ok', всего было 3 попытки (attempt === 3)

    // а если unstable всегда бросает ошибку:
    await retry(alwaysFails, 3, 10)
    // -> отклоняется, всего было 3 попытки, дальше не пробует


ОГРАНИЧЕНИЕ

Без внешних библиотек. delay реализовать вручную через Promise
(setTimeout сам по себе колбэковый, промисов не возвращает).
