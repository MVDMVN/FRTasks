ЗАДАЧА 5 — TOGGLE ITEM (иммутабельное обновление массива)


О ЧЁМ ЗАДАЧА

Это то, что ты наверняка уже писал в React руками, в каком-нибудь
setTodos(prev => ...). Здесь то же самое, но отдельно от React — просто
функция.

Есть список задач (todo list). Нужно переключить одну задачу по id
(done: true <-> false), не трогая исходный массив.


ЧТО ИМЕННО ПИСАТЬ

Файл solution.js:

    export function toggleTodo(todos, id) { ... }

todos — массив вида [{ id: string, title: string, done: boolean }, ...]
id    — id задачи, у которой нужно перевернуть done

Возвращает НОВЫЙ массив: у задачи с этим id done становится
противоположным, остальные задачи — как были (те же объекты, не пересозданные
без нужды).

Если задачи с таким id нет — вернуть массив без изменений (но всё равно
новый массив, не тот же самый по ссылке).


ПРИМЕР

    const todos = [
      { id: '1', title: 'Купить хлеб', done: false },
      { id: '2', title: 'Сделать задачу', done: false },
    ]

    const result = toggleTodo(todos, '2')

    result
    // [
    //   { id: '1', title: 'Купить хлеб', done: false },
    //   { id: '2', title: 'Сделать задачу', done: true },
    // ]

    todos[1].done
    // false — исходный массив не тронут


ОГРАНИЧЕНИЕ (в этом весь смысл)

Нельзя мутировать todos или объекты внутри него напрямую (никаких
todos[i].done = ..., push, splice и т.п.). Как и в React — только через
создание новых объектов/массивов.

Подсказка по инструменту: map + spread (...).
