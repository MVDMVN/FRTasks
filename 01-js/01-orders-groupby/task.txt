ЗАДАЧА 1 — КТО СКОЛЬКО У НАС ПОТРАТИЛ


О ЧЁМ ЗАДАЧА

Есть интернет-магазин. У нас лежит плоский список заказов — просто массив,
заказы разных клиентов вперемешку, часть оплачена, часть нет.

Нужен отчёт для бухгалтерии: список клиентов и сколько денег каждый нам
реально принёс. Кто больше всех потратил — тот сверху.

То есть: на входе список ЗАКАЗОВ, на выходе список КЛИЕНТОВ.


ЧТО НАДО СДЕЛАТЬ, ПО ШАГАМ

1. Выкинуть все заказы, кроме оплаченных (status === 'paid').
   Отменённые и ждущие оплаты денег нам не принесли — их вообще не считаем.

2. Для каждого оставшегося заказа посчитать его сумму.
   Формула: сложить price * qty по всем позициям заказа.
   Пример: Мышь 1500 x 2 + Коврик 500 x 1 = 3500

3. Сгруппировать заказы по клиенту. Группируем по полю customerId
   (не по имени — имена могут совпадать, id уникален).

4. По каждому клиенту посчитать две цифры:
   - ordersCount — сколько у него оплаченных заказов
   - total — сколько денег он потратил всего (сумма сумм его заказов)

5. Отсортировать клиентов по total, от большего к меньшему.
   Если у двоих total одинаковый — тогда по имени по алфавиту (localeCompare).

6. Вернуть массив.


ПРИМЕР

Вход:

    const orders = [
      { id: 'o1', customerId: 'c1', customerName: 'Анна', status: 'paid',
        items: [{ title: 'Мышь', price: 1500, qty: 2 },
                { title: 'Коврик', price: 500, qty: 1 }] },

      { id: 'o2', customerId: 'c1', customerName: 'Анна', status: 'paid',
        items: [{ title: 'Клавиатура', price: 4000, qty: 1 }] },

      { id: 'o3', customerId: 'c2', customerName: 'Борис', status: 'paid',
        items: [{ title: 'Монитор', price: 20000, qty: 1 }] },

      { id: 'o4', customerId: 'c2', customerName: 'Борис', status: 'cancelled',
        items: [{ title: 'Ноутбук', price: 90000, qty: 1 }] },

      { id: 'o5', customerId: 'c3', customerName: 'Виктор', status: 'pending',
        items: [{ title: 'Кресло', price: 50000, qty: 1 }] },
    ]

Выход:

    summarizeOrdersByCustomer(orders)

    [
      { customerId: 'c2', customerName: 'Борис', ordersCount: 1, total: 20000 },
      { customerId: 'c1', customerName: 'Анна',  ordersCount: 2, total: 7500  },
    ]

Разбор, почему получилось именно так:

  Борис  — заказ o3 на 20000. Заказ o4 отменён, 90000 не считаем.
           Поэтому ordersCount: 1, total: 20000.

  Анна   — заказ o1: 1500*2 + 500*1 = 3500
           заказ o2: 4000*1        = 4000
           итого 2 заказа на 7500.

  Виктор — в отчёт не попал вообще. Его единственный заказ в статусе
           pending, оплаченных заказов у него ноль, значит и строки нет.

  Борис выше Анны, потому что 20000 > 7500.

ДОПОЛНИТЕЛЬНО

- Пустой массив на входе → пустой массив на выходе, без падений.
- Исходный массив orders не менять (не мутировать). Возвращаем новые объекты.


ОГРАНИЧЕНИЕ (в этом весь смысл упражнения)

Решаем через map / filter / reduce. Плюс можно sort и Object.values.

Нельзя: цикл for/while или forEach, который накапливает результат
во внешнюю переменную. Именно от этой привычки и уходим.
