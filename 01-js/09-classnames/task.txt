ЗАДАЧА 9 — CLASSNAMES (rest-параметры функции)


О ЧЁМ ЗАДАЧА

В JSX часто пишут что-то вроде:

    <div className={`btn ${isActive ? 'active' : ''} ${size === 'lg' ? 'btn-lg' : ''}`}>

Это быстро превращается в кашу из пробелов и пустых строк. Есть популярная
библиотека classnames (или clsx) именно для этого. Сейчас напишем свою
маленькую версию.


ЧТО ИМЕННО ПИСАТЬ

Файл solution.js:

    export function cx(...classes) { ... }

cx принимает ЛЮБОЕ количество аргументов (это и есть rest-параметры —
...classes собирает все переданные аргументы в один массив внутри функции).

Каждый аргумент — это либо строка (имя класса), либо falsy-значение
(undefined, null, false, '', 0) — то, что получается из условий вида
isActive && 'active'.

Нужно взять только настоящие строки-классы и склеить их через пробел.


ПРИМЕР

    cx('btn', 'primary')
    // 'btn primary'

    cx('btn', false && 'active', 'primary')
    // 'btn primary' — false выброшен

    cx('btn', undefined, null, '', 'primary')
    // 'btn primary' — все falsy выброшены

    cx()
    // '' — пустая строка, если классов нет вообще


ОГРАНИЧЕНИЕ

Использовать rest-параметры (...classes) в сигнатуре функции — не array
как обычный параметр, не arguments.
