# FrontStudy

Практика по плану из [MENTOR.md](MENTOR.md).

## Структура

Одна задача — одна папка внутри этапа:

```
01-js/01-orders-groupby/
├── task.md            условие
├── solution.js        решаю я
└── solution.test.js   тесты — критерий «готово»
```

Этапы: `01-js` → `02-react` → `03-typescript` → `04-react-native`.

## Как запускать

Все тесты проекта:

```bash
npm test
```

Одну задачу:

```bash
node --test 01-js/01-orders-groupby/
```

В режиме watch (перезапуск при сохранении):

```bash
npm run test:watch
```

Зависимостей нет: тест-раннер встроен в Node (>= 18). Vite/Vitest подключим
на этапе React.

## Правила игры

- Решаю сам 20–30 минут, гуглю, читаю доки.
- Ментор не подсказывает, пока не скажу «застрял».
- Готово = зелёные тесты, дальше короткий разбор.
