FRONTSTUDY

Обучение JS по оглавлению learn.javascript.ru с наставником-ИИ.


ФАЙЛЫ

    CLAUDE.md         правила работы наставника (читается автоматически)
    MENTOR.md         состояние обоих треков: что сейчас, что дальше
    STATS.md          измерения, перепроверки через неделю, история тем
    FORMULATIONS.md   устные формулировки к собеседованию (пока на паузе)


ДВА ТРЕКА

    react/   практика (~60% времени) — учебное приложение на Next.js,
             пишу сам, ментор только ревьюит
    js/      теория (~40%) — главы Кантора, задачи с тестами

Цель — собеседование на мидл-React.

Личный проект UltimaUtil лежит отдельно и к обучению отношения не имеет.


СТРУКТУРА (с 2026-09-19, идём по оглавлению learn.javascript.ru)

Папка главы — номер главы. Внутри — папка темы: номер темы + короткий
английский slug. Если по теме несколько задач — подпапка на каждую:

    02/
      2.4-variables/
        01-first-task/
          task.txt           условие
          solution.js        решаю я
          solution.test.js   тесты — критерий «готово»

Если задача по теме одна — файлы можно класть прямо в папку темы, без
лишней вложенности.

Порядок тем и текущий прогресс — в MENTOR.md.


КАК ЗАПУСКАТЬ

Все тесты проекта:

    npm test

Одну задачу:

    node --test 01-js/01-orders-groupby/

В режиме watch (перезапуск при сохранении):

    npm run test:watch

Зависимостей нет: тест-раннер встроен в Node (>= 18).
Vite/Vitest подключим на этапе React.


ПРАВИЛА ИГРЫ

- Решаю сам 20–30 минут, гуглю, читаю доки.
- Ментор не подсказывает, пока не скажу «застрял».
- Готово = зелёные тесты, дальше короткий разбор.
